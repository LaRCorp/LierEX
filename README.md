**LierEX** — лёгкое расширение (Manifest V3) без сборщиков и внешних зависимостей. Оно извлекает метаданные и обложки со страниц популярных кинобаз и игровых магазинов и в один клик передаёт их в настольное приложение **[Lierkour](https://github.com/LaRCorp/Lierkour)** через локальный HTTP-мост `http://127.0.0.1:8765`.

> **Распространение:** в данный момент расширение распространяется **только через GitHub** (исходный код и готовый архив в разделе [Releases](https://github.com/LaRCorp/LierEX/releases)) — установка занимает меньше минуты через «Режим разработчика» в любом Chromium-браузере.

## Основные возможности

- **Выбор статуса до добавления в библиотеку:**
  - Фильмы / сериалы / аниме: `В планах`, `Смотрю`, `Просмотрено`, `Брошено`.
  - Игры: `В планах`, `Играю`, `Пройдена`, `Брошена`.
- **Обработка игровых обложек:** передача списка кандидатов постера в Lierkour, где горизонтальные баннеры игр (Steam / Epic / Itch / GOG) аккуратно оформляются под единый вертикальный формат карточек `600×900` с размытым фоном без обрезки.
- **Автолокализация интерфейса (RU / EN):** язык popup-окна и системных сообщений автоматически подстраивается под язык браузера (`_locales/en` и `_locales/ru`).
- **Локальность и приватность:**
  - Минимальные права Manifest V3: `activeTab`, `scripting`, `storage`.
  - Отсутствует `<all_urls>`, фоновый сбор истории и любая телеметрия.
  - Парсинг выполняется только в момент нажатия на иконку расширения.
  - Локальный импорт защищён заголовком `X-LierEX-Token`.

## Установка с GitHub (Edge, Chrome, Яндекс, Brave, Opera, Vivaldi)

> Расширение работает в любом браузере на базе **Chromium** (Microsoft Edge, Google Chrome, Яндекс.Браузер, Brave, Opera, Vivaldi).

### Способ 1 — скачать архив (рекомендуется)
1. Перейдите на страницу **[Releases LierEX](https://github.com/LaRCorp/LierEX/releases)** (или нажмите на GitHub кнопку **Code → Download ZIP**).
2. **Распакуйте** архив в постоянную папку, которую не будете удалять (например, `C:\Apps\LierEX` — браузер считывает файлы расширения прямо оттуда).
   - *Важно:* внутри выбранной папки сразу должен лежать файл `manifest.json`.
3. Откройте страницу расширений вашего браузера:
   - Microsoft Edge: `edge://extensions/`
   - Google Chrome: `chrome://extensions/`
   - Яндекс.Браузер: `browser://extensions/`
   - Brave: `brave://extensions/`
4. Включите переключатель **«Режим разработчика»** (Developer mode).
5. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите папку с `manifest.json`.
6. Закрепите иконку **LierEX** на панели инструментов браузера.

### Способ 2 — через Git
```bash
git clone https://github.com/LaRCorp/LierEX.git
```
Далее выполните шаги 3–6 и укажите клонированную папку `LierEX`. Для обновления до новой версии достаточно выполнить `git pull` и нажать кнопку обновления на карточке расширения в браузере.

## Подключение к Lierkour и использование

1. Установите и запустите десктопное приложение **[Lierkour (v2.1+)](https://github.com/LaRCorp/Lierkour/releases)**.
2. В Lierkour откройте вкладку **«Настройки»** и найдите блок **«Связь с браузерным расширением LierEX»**.
3. Убедитесь, что отображается статус активности (`127.0.0.1:8765`), и нажмите **«Копировать»** рядом с токеном `X-LierEX-Token`.
4. Нажмите на иконку **LierEX** в браузере → значок **⚙** → вставьте токен → нажмите **OK** (токен сохранится в локальном `chrome.storage.local` браузера).
5. Откройте карточку нужного фильма, сериала или игры на одном из 8 поддерживаемых сайтов и нажмите на иконку **LierEX**.
6. Проверьте извлечённые данные и постер, выберите нужный **статус** и нажмите **«Добавить в Lierkour»** — карточка сразу откроется для просмотра или редактирования в приложении.

## Структура исходного кода

```text
LierEX/
├── manifest.json             # Манифест Manifest V3
├── background.js             # Воркер: проверка домена, инъекция парсера, отправка в 127.0.0.1:8765
├── content.js                # Адаптеры извлечения данных для 8 сервисов
├── popup.html                # Разметка всплывающего окна
├── popup.css                 # Стили (тёмная тема, превью обложки, бейджи)
├── popup.js                  # Логика popup, смена статуса, настройка токена, i18n
├── _locales/
│   ├── en/messages.json      # Английская локализация
│   └── ru/messages.json      # Русская локализация
├── icons/                    # Иконки 16×16, 48×48, 128×128
├── LICENSE                   # Лицензия GNU GPLv3
└── README.md
```
